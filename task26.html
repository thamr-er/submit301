exit() System Call

What is exit()?

The exit() system call is used in Operating Systems to terminate a process. When a process finishes its execution or encounters an error, it calls exit() to stop running and return control back to the Operating System.

In Linux and UNIX systems, exit() also returns an exit status code to the parent process. A status of 0 usually means successful execution, while any non-zero value indicates an error.

Important Features of exit()

  • Terminates the current process.
  • Returns an exit status to the parent process.
  • Closes open files and releases memory resources.
  • Removes the process from the CPU scheduling queue.
  • Helps the Operating System clean up process resources.

C Example Using exit()

#include <stdio.h> #include <stdlib.h> int main() { printf("Program is running...\n"); exit(0); printf("This line will never execute."); return 0; }

In this example, the program stops immediately when exit(0) is called. The statement after exit() will never run.

How exit() Works Internally

When a process calls exit(), the Operating System performs several actions:

  • Stops process execution.
  • Stores the exit status code.
  • Releases memory allocated to the process.
  • Closes open file descriptors.
  • Notifies the parent process using wait().

Advantages of exit()

  • Provides clean process termination.
  • Helps prevent memory leaks.
  • Allows parent processes to detect child completion.
  • Improves resource management inside the Operating System.
