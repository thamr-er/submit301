CPU Privilege Rings

Dual-Mode Operation

Modern CPUs enforce hardware privilege rings to protect the OS kernel. Applications run in User Mode (Ring 3) with restricted access. To interact with hardware, they issue a system call to enter Kernel Mode (Ring 0).
