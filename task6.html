What is a Process State?

A process is a program in execution. Unlike a static program on disk, a process is alive — it has memory, registers, and an identity (PID). The operating system must manage many processes at once, so it assigns each one a state that describes what it's currently doing or waiting for. This is stored in the Process Control Block (PCB).

🆕
New
Process just created. OS allocates a PCB and sets up initial resources. Not yet admitted to memory.
⏳
Ready
Loaded in memory, all resources available. Waiting in the ready queue for CPU time.
⚡
Running
CPU is actively executing this process. Only one process per core can be Running at once.
💤
Waiting
Blocked on an event — usually I/O. Cannot use the CPU until the event completes.
✓
Terminated
Execution finished or process was killed. OS reclaims all resources and removes the PCB.

04

Summary

Process state management is the heartbeat of any OS. Without it, the CPU wouldn't know which process to run next, which to pause, or which to remove. The five-state model — New → Ready → Running → Waiting → Terminated — is the conceptual foundation of all modern process scheduling, from Linux to Windows. Real systems extend this with states like Swapped-Ready and Zombie, but the core model remains unchanged.
