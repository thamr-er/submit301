The fork() System Call

Lab & System Calls Category (Topic #24)

What is fork()?

In Unix-like operating systems, the fork() system call is used to create a new process by duplicating the calling process. The existing process is called the Parent Process, and the newly created process is called the Child Process.

Key Characteristics:

  • Exact Clone: The child process gets a copy of the parent's text (code), data, heap, and stack segments. However, they run in completely separate memory spaces.
  • Execution Point: The child does not start from the beginning of main(). It begins execution right from the exact point where fork() returns.
  • Return Value (Crucial for Control):
    • Returns 0 inside the Child Process.
    • Returns the PID of the child inside the Parent Process.
    • Returns -1 if the creation fails.
Why the return value matters: Because the parent and child contain identical code, the program uses the return value of fork() to make the parent and child behave differently using conditional statements (if/else).

Standard C Implementation

#include <stdio.h>
#include <unistd.h>

int main() {
    pid_t pid;
    
    // Create a child process
    pid = fork(); 
    
    if (pid < 0) {
        printf("Fork Failed!\n");
    } else if (pid == 0) {
        // Child process execution
        printf("Hello from Child!\n");
    } else {
        // Parent process execution
        printf("Hello from Parent! Child PID: %d\n", pid);
    }
    return 0;
}
