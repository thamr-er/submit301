lseek()

A system call that moves the file cursor — the internal pointer that tracks where the next read or write will happen inside an open file.

// What it does

Every open file has a hidden offset — a number that says "we are currently at byte N." When you call read() or write(), they use that offset and then advance it automatically.

lseek() lets you jump that offset to any byte position you want — forward, backward, or relative to the end — without reading or writing anything.

// Syntax

// include the header
#include <unistd.h>

off_t lseek(int fd, off_t offset, int whence);
Parameter Description
fd File descriptor — the number returned by open() that refers to your open file.
offset How many bytes to move. Can be positive (forward) or negative (backward).
whence SEEK_SET — measure offset from byte 0 (start of file)
SEEK_CUR — measure offset from the current cursor position
SEEK_END — measure offset from the end of the file
returns The new cursor position as a byte number. Returns -1 on error.

// C Example

// File contains: "Hello, World!" (13 bytes, index 0–12)

int fd = open("file.txt", O_RDONLY);

lseek(fd, 7, SEEK_SET); // jump to byte 7 → 'W'
lseek(fd, 2, SEEK_CUR); // move 2 forward → byte 9 → 'r'
lseek(fd, -1, SEEK_END); // go to last byte → byte 12 → '!'

// trick: find current position without moving
off_t pos = lseek(fd, 0, SEEK_CUR);
