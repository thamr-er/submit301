What is SJF Scheduling?

Shortest Job First (SJF) is a CPU scheduling algorithm where the process with the smallest burst time is executed first. The operating system estimates which process will finish the fastest and schedules it before longer jobs.


SJF minimizes average waiting time and is considered one of the most efficient scheduling algorithms. However, it may cause starvation, where longer processes wait too long if short jobs keep arriving.

  • Type: Non-Preemptive Scheduling Algorithm
  • Main Goal: Reduce average waiting time
  • Advantage: Fast average performance
  • Disadvantage: Long processes may starve

How the Algorithm Works

The scheduler compares all available processes and chooses the one with the smallest CPU burst time. After that process finishes, the scheduler again selects the shortest remaining job.


Example:

  • P1 = 6 ms
  • P2 = 2 ms
  • P3 = 8 ms
  • P4 = 3 ms

Execution Order → P2 → P4 → P1 → P3
