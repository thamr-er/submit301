sleep() System Call

The sleep() system call pauses a process for a set amount of time. During that pause, the process is moved into a waiting state, and the CPU can run other processes instead. This page shows the idea in a simple visual demo.

Explanation

You can think of sleep() like a timer that tells a program to take a break. The program does not crash or stop forever. It just waits, and then continues after the chosen number of seconds has passed.

Key point: the process is temporarily paused, but the operating system keeps running normally and may schedule another process on the CPU.

Uses of sleep():

  • adding delays between actions
  • waiting before retrying a task
  • making animations or timed loops easier to control

C example:

#include <unistd.h> #include <stdio.h> int main() { printf("Before sleep\n"); sleep(3); printf("After 3 seconds\n"); return 0; }

In the example, the program prints one message, sleeps for 3 seconds, and then continues.
