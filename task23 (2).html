lseek()

Linux System Call — File Offset Control

What is lseek()?

Every open file has a file offset — a cursor that tracks where the next read() or write() will happen. By default, each call advances this cursor automatically. lseek() lets you move the cursor anywhere in the file without reading or writing.

Signature: off_t lseek(int fd, off_t offset, int whence);

It returns the new absolute position in the file on success, or -1 on error. The third argument whence controls how offset is interpreted:

SEEK_SET
Value: 0
Move to offset bytes from the start of the file.
SEEK_CUR
Value: 1
Move offset bytes from the current position.
SEEK_END
Value: 2
Move offset bytes from the end of the file (usually negative).

Lab Examples (from class)

Double read()
Read 10 bytes twice — cursor moves automatically after first read.
read(f,b,10);
read(f,b,10);
SEEK_CUR
Skip 10 bytes from current position, then read.
lseek(fd,10,SEEK_CUR);
read(f,b,10);
SEEK_SET
Jump to absolute byte 10 from start, then read.
lseek(f,10,SEEK_SET);
read(f,b,10);
SEEK_END
Go 11 bytes back from the end, then read.
lseek(f,-11,SEEK_END);
read(f,b,10);
